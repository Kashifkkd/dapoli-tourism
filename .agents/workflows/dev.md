# Development Workflow

## Start Dev Server
// turbo
1. Run `npm run dev` from the project root to start the Next.js development server with Turbopack
2. Open `http://localhost:3000` in your browser

## Build for Production
// turbo
3. Run `npm run build` to create a production build
4. Run `npm run start` to serve the production build

## Lint
// turbo
5. Run `npm run lint` to check for linting issues

## Key Directories
- `app/` — Pages, layouts, and components
- `app/components/` — Reusable UI components
- `public/images/` — Static images
- `wanderlux/` — Stitch UI reference HTML files (do not modify)
